# Dossier données

Ce dossier doit contenir `Analyse_environnementale.gpkg` avant de zipper
le plugin pour l'installer dans QGIS.

Le fichier n'est **pas** versionné dans ce dépôt Git (trop volumineux :
> 100 Mo, limite GitHub). Téléchargez la dernière version depuis
l'onglet **Releases** de ce dépôt, et placez-la ici sous le nom exact
`Analyse_environnementale.gpkg`.
